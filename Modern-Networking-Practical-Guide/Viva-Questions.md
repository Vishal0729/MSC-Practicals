# Viva Questions and Answers

## Static Routing
**Q:** What is static routing?  
**A:** Routes are manually entered by the admin.

**Q:** Why use static routing?  
**A:** It is simple and predictable.

## Inter-VLAN Routing
**Q:** Why do we need inter-VLAN routing?  
**A:** Devices in different VLANs need a router or Layer 3 switch to talk.

**Q:** What is a trunk?  
**A:** A trunk carries traffic for many VLANs.

## PBR
**Q:** What is PBR?  
**A:** Policy Based Routing lets you choose a path based on rules, not only the routing table.

## IP SLA
**Q:** What is IP SLA?  
**A:** A built-in test tool that checks whether a path is alive.

## BGP
**Q:** What is eBGP?  
**A:** BGP between different autonomous systems.

**Q:** What is iBGP?  
**A:** BGP inside the same autonomous system.

## AS_PATH
**Q:** What is AS_PATH?  
**A:** A list of AS numbers a route has crossed.

## Local Preference
**Q:** What does local preference do?  
**A:** It chooses the preferred exit from an AS.

## MED
**Q:** What does MED do?  
**A:** It suggests which entry point another AS should use.

## Security
**Q:** Why use SSH instead of Telnet?  
**A:** SSH encrypts traffic.

## VRF
**Q:** What is VRF?  
**A:** It creates separate routing tables on the same router.

## MPLS
**Q:** Why is MPLS used?  
**A:** It uses labels to move traffic efficiently.
