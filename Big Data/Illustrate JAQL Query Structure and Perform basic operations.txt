# Part 1: Illustrate JAQL Query Structure (10 Marks)

## Step 1: Read JSON Dataset

```jaql
employees = read("employee.json");
```

---

## Step 2: Display Dataset

```jaql
employees;
```

---

## Step 3: Projection (Select Specific Fields)

```jaql
employees -> transform {
    name,
    salary
};
```

---

## Step 4: Rename Fields

```jaql
employees -> transform {
    EmployeeName : name,
    EmployeeSalary : salary
};
```

---

## Step 5: Sort Records

```jaql
employees -> sort by salary;
```

Descending

```jaql
employees -> sort by salary desc;
```

---

## Step 6: Count Records

```jaql
employees -> aggregate count($);
```

---

# Part 2: Perform Basic Operations (5 Marks)

## Filter Employees from IT Department

```jaql
employees
-> filter $.department == "IT";
```

---

## Filter Salary Greater Than 50000

```jaql
employees
-> filter $.salary > 50000;
```

---

## Group by Department

```jaql
employees
-> group by $.department into g
-> transform {
    Department : key,
    Employees : count(g)
};
```

---

## Average Salary Department-wise

```jaql
employees
-> group by $.department into g
-> transform {
    Department : key,
    AverageSalary : avg(g.salary)
};
```

---

## Maximum Salary

```jaql
employees
-> aggregate max($.salary);
```

---

## Minimum Salary

```jaql
employees
-> aggregate min($.salary);
```

---

## Total Salary

```jaql
employees
-> aggregate sum($.salary);
```

---

## Top 5 Employees

```jaql
employees
-> sort by salary desc
-> limit 5;
```

# JAQL Query Structure

The basic syntax of a JAQL query is:

```jaql
input
-> operation1
-> operation2
-> operation3;
```

Example:

```jaql
employees
-> filter $.salary > 50000
-> sort by salary desc
-> transform {
    name,
    salary
};
```

# Viva Questions

**Q1. What is JAQL?**

JAQL (JSON Query Language) is a functional query language used to process, transform, and analyze JSON data.

**Q2. Which data format does JAQL primarily work with?**

JSON (JavaScript Object Notation).

**Q3. What is the purpose of the `filter` operation?**

It selects records that satisfy a specified condition.

**Q4. What is the purpose of the `transform` operation?**

It projects or reshapes data by selecting or renaming fields.

**Q5. What are common aggregation operations in JAQL?**

* `count()`
* `sum()`
* `avg()`
* `max()`
* `min()`

**Q6. What is the purpose of the `group` operation?**

It groups records based on a common field so that aggregation can be performed.
